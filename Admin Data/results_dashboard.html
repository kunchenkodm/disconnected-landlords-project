Model Taxonomy

Each estimate is defined by four dimensions: Model (estimation strategy), Spec (covariate set), Matching Core (sample used for PSM matching), and Regression Core (sample used for regression). Not all combinations are valid.

Models (8)

Model Description
OLS Additive FEOLS with year + property type + fuel + age + form + LA as separate fixed effects
OLS Interactive FEOLS with a single fully interacted FE (year × type × fuel × age × form × LA)
PSM (Matched)Nearest-neighbour propensity score matching, no caliper
PSM + Subclass FESame matching + subclass (pair) fixed effects in regression
PSM PS≤0.2Matching with 0.2 propensity score caliper
PSM PS≤0.2 + Sub FE0.2 caliper + subclass FE
PSM PS≤0.1Matching with 0.1 propensity score caliper
PSM PS≤0.1 + Sub FE0.1 caliper + subclass FE

OLS models use matching core = (none). PSM models exact-match on lodgement year, property type, fuel, age band, built form, and local authority.

Data Cores (4)

Core Sample restriction
baseAll observations (no additional data requirements)
council_taxOnly properties with council tax band data
ppdOnly properties with Price Paid transaction data
ppd_counciltaxOnly properties with both PPD and council tax (most restrictive)

Different cores restrict to different samples. Comparisons across cores compare different populations. The specification curve groups rows by regression core for this reason.
