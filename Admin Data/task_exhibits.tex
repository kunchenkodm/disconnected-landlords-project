\noindent This document assembles the tables and figures for the four PI-feedback
tasks. \textbf{Sign conventions:} \texttt{current\_energy\_efficiency} (EPC/SAP
score) is \emph{higher = more efficient (better)}; matched-pair effects are
treated minus control, so a \emph{positive} value means the ownership type is
\emph{more efficient than its matched private-individual control}.
\texttt{bad\_epc\_c} is the share below EPC band C (\emph{higher = worse}).
Archetypes are referred to throughout by the short names defined in
Table~\ref{tab:hte_archetypes}.
